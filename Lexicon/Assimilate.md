# Assimilate

əˈsɪm.ɪ.leɪt

- to learn something so that it is fully understood and can be used
- to cause, a person or group, to become part of a different society, country, etc.
- to adopt the ways of another culture

Similar words: [[Understand]], [[Integrate]]

Mnemonic: Assimilate, sounds like accumulate: acquiring knowledge; joining together.

Example: It's hard to assimilate so much information.
