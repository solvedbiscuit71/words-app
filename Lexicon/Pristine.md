# Pristine

pris·​tine

- belonging to the earliest period or state : original
- not spoiled, corrupted, or polluted (as by civilization) : pure
- fresh and clean as or as if new

Similar words: [[Mint]], [[Clean]]

Near antonyms: [[Stale]], [[Filthy]]

Mnemonic: Angular form property pristine tells us whether the user has changed the input value in UI.
